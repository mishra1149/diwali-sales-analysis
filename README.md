# diwali-sales-analysis
 Diwali Sales Analysis
📌 Project Overview
This project focuses on analyzing Diwali sales data using Python to understand sales patterns, product performance, and customer purchasing behavior.
The main purpose of this project was to explore the dataset, perform data analysis, create visualizations, and extract meaningful insights from the sales data.
🛠️ Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
🔍 Analysis Performed
Explored and understood the sales dataset
Performed data cleaning and preparation
Analyzed sales across different product categories
Analyzed product-wise orders
Identified the top-selling products
Compared the performance of different product categories
Created visualizations to understand sales and order patterns
📊 Key Insights
Food was one of the highest-performing product categories.
Clothing & Apparel and Electronics & Gadgets also showed strong performance.
Some individual products received significantly higher orders than others.
Category-wise and product-wise analysis helped identify the better-performing areas of the business.
